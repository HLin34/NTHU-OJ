# NTHU Online Judge — C Programming Practice

A collection of C programming solutions developed during my **Introduction to Programming** course at National Tsing Hua University (NTHU).

This repository documents my early programming experience, including problem-solving exercises, practice problems, and course-related assessments using the NTHU Online Judge platform.

## About NTHU Online Judge

[NTHU Online Judge](https://acm.cs.nthu.edu.tw/) is an online programming judge maintained by National Tsing Hua University for programming practice and contests.

Each solution is named according to its problem ID. To view the original problem statement, visit the NTHU Online Judge website and search for the corresponding problem number.

## Repository Structure

| Directory | Description |
|---|---|
| `practice-problems/` | Programming practice problems and solutions |
| `final-exam/` | Final examination-related programming exercises |
| `bonus-problems/` | Additional programming exercises |
| `pointer-practice/` | C pointer practice |
| `midterm-problem-list.docx` | Midterm practice problem reference |

## Programming Language

- **C**

The exercises provide practice with fundamental programming concepts, including control flow, functions, arrays, pointers, and problem-solving techniques.

## Running the Programs

Most solutions are standalone C programs and can be compiled using GCC.

For example:

```bash
gcc bonus-problems/12140.c -o solution
./solution
```

On Windows, the generated executable can be run using:

```bash
.\solution.exe
```

Replace `12140.c` with the filename of the problem you want to run.

Input and output requirements depend on the corresponding problem statement on NTHU Online Judge.
